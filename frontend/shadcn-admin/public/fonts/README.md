# Pharmaviyum web fonts

Place the licensed Mokoto webfont here as:

`Mokoto.woff2`

Only add a font file covered by a license that permits webfont use and distribution with this application. Do not copy the Mokoto font file from Canva into this repository.

Once the licensed file is available, register it with `@font-face` in `src/styles/index.css` and keep the `.pharmaviyum-brand` family pointed at `Mokoto`.
