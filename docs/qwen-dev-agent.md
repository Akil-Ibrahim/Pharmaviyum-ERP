## Агент разработчика на Qwen (3.6 / 3.7)

Цель: дать разработчикам удобный локальный агент, использующий Mortarium AI (локальный Qwen), который понимает код и помогает с ревью, навигацией и подсказками.

Ключевые идеи:
- Агент не содержит модель в репозитории — модель устанавливается локально и монтируется/указываетcя через `MODEL_PATH`.
- Рекомендуемые версии: Qwen 3.6 или Qwen 3.7 (Instruct / GGUF variants).
- Для установки бесплатной легкой модели используй `tools/install_qwen_model.py`.

Как использовать локально:
1. Скачай модель с помощью `tools/install_qwen_model.py`.
2. Помести модель в локальную папку, например `./models/qwen3/`.
3. Запусти сервис Mortarium AI, указав `MODEL_PATH` на скачанный файл или смонтировав папку в контейнер.
4. Используй CLI-клиент `tools/qwen_dev_agent.py` для отправки кодовых запросов и получения ответов.

Примеры запросов, которые работают хорошо:
- "Объясни, что делает функция xyz в `src/pharmaviyum/...` и предложи упрощение"
- "Найди потенциальные проблемы с безопасностью в `src/pharmaviyum/auth.py`"
- "Сгенерируй unit-тест для `MyClass.method()`"

Подсказки для промпта (в CLI / UI):
- Указывай контекст файла/папки и цель (рефакторинг, тест, багфикс).
- Проси шаги, изменения в коде и конкретные патчи в формате diff.

Ограничения и безопасность:
- Агент отвечает на основе локальной модели; при отсутствии модели — Mortarium вернёт mock-ответы.
- Не загружай в модель приватные ключи, пароли или реальные данные.

Дальше можно: интегрировать этот клиент в редактор (VS Code task/snippet) или добавить CI-валидацию промптов.
