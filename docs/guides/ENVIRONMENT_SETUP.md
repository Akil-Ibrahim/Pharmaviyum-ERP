# Environment Setup Guide

## 🚀 Quick Start

### Development (Local)

```bash
# 1. Setup development environment
bash scripts/setup-env.sh dev

# 2. Start services
docker-compose up -d

# 3. Access application
# Backend: http://localhost:8000
# API Docs: http://localhost:8000/api/docs
# Frontend: http://localhost:3000

# Login credentials:
# Email: Admin
# Password: Admin1989
```

### Production

```bash
# 1. Generate secure secrets
bash scripts/generate-secrets.sh

# 2. Setup production environment
bash scripts/setup-env.sh prod

# 3. Edit .env.production
nano .env.production
# Update: ADMIN_EMAIL, ALLOWED_ORIGINS, SENTRY_DSN

# 4. Start production services
docker-compose -f docker-compose.prod.yml up -d

# 5. Verify health
curl http://localhost/health
```

## 📁 Environment Files

| File | Purpose | When to use |
|------|---------|-------------|
| `.env.development` | Local development | Development on localhost |
| `.env.production` | Production deployment | Live server with real data || `.env` | Active configuration | Auto-generated by setup script |

## 🔐 Security Checklist

### Development ✅
- [ ] DEBUG=true
- [ ] Weak passwords OK
- [ ] Rate limiting disabled
- [ ] Local database
- [ ] No sensitive data

### Production ✅
- [ ] DEBUG=false
- [ ] Strong secrets generated
- [ ] Rate limiting enabled
- [ ] Production database with backups
- [ ] SSL/TLS configured
- [ ] CORS restricted to specific domains
- [ ] Sentry monitoring enabled
- [ ] .env in .gitignore

## 🔄 Switching Environments

```bash
# Switch to development
bash scripts/setup-env.sh dev
docker-compose down
docker-compose up -d

# Switch to production
bash scripts/setup-env.sh prod
docker-compose down
docker-compose -f docker-compose.prod.yml up -d
```

## 📋 Useful Commands

```bash
# View current environment
cat .env | grep -E "^(DEBUG|ENVIRONMENT|ADMIN_EMAIL)"

# Generate new secrets
bash scripts/generate-secrets.sh

# Backup production database
docker-compose -f docker-compose.prod.yml exec postgres pg_dump -U pharmaviyum pharmaviyum_prod > backup.sql

# View logs
docker-compose logs -f backend
# Restart services
docker-compose restart backend
```

## ⚠️ Important Notes

1. **Never commit .env files** - they are in .gitignore
2. **Use different secrets** for each environment
3. **Rotate secrets regularly** in production
4. **Backup production data** before any changes
5. **Test in development** before deploying to production
