# Python Core & Advanced Python — Русская версия

Используйте эту папку для изучения материала и понимания технических концепций на русском языке.

**Базовая версия:** Python 3.15.2. Поведение, зависящее от версии, необходимо явно отмечать, а гарантии языка — отделять от деталей реализации CPython.

- [Карта вопросов](./PYTHON_CORE_ADVANCED.md) — темы, идентификаторы и порядок изучения.
- [Вопросы и ответы](./PYTHON_CORE_ADVANCED_QUESTIONS_AND_ANSWERS.md) — объяснения и готовые ответы для собеседования.
- [English version](../EN/README.md)

Сначала изучайте основной вопрос, затем четыре Follow-up. Важно понять объяснение, а уже после этого отрабатывать краткий ответ для интервью. Английская версия использует те же идентификаторы вопросов.

**Текущее покрытие:** PY-001–PY-019 и 76 дополнительных вопросов (FU-1–FU-4 для каждого основного вопроса).
