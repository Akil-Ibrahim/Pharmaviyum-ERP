# Library Skills и инструменты FastAPI для ИИ-агентов

Pharmaviyum использует [Library Skills](https://library-skills.io/) для обнаружения инструкций для агентов, поставляемых установленными Python- и JavaScript/TypeScript-зависимостями. FastAPI также включает официальный навык для работы с фреймворком в своём Python-пакете. Плагин FastAPI Cloud — отдельная интеграция для облачных операций.

Инструкции версионируются вместе с библиотеками, которые их поставляют. Они помогают coding agents использовать поддерживаемые API и актуальные соглашения библиотек, но сами по себе не запускают код приложения и не меняют production-зависимости.

Текущая проверка Python-зависимостей обнаруживает официальный навык `fastapi`, поставляемый закреплённым в проекте дистрибутивом FastAPI 0.164.0 после синхронизации зависимостей. В Pharmaviyum он доступен по пути `.agents/skills/fastapi` через относительную symlink-ссылку, управляемую репозиторием и ведущую к установленному пакету FastAPI. Так инструкции соответствуют версии FastAPI в проекте. Навык берётся из официального дистрибутива FastAPI, а не копируется вручную в репозиторий. Текущая проверка frontend-зависимостей не обнаруживает навыков, поставляемых пакетами.

## Навык FastAPI

### Текущая настройка проекта

Навык FastAPI уже присутствует в репозитории:

```text
.agents/skills/fastapi
```

Это управляемая symlink-ссылка на установленный дистрибутив FastAPI. Не заменяйте её вручную скопированным каталогом и не редактируйте ссылку вручную. После установки или обновления Python-зависимостей проверьте управляемые ссылки:

```bash
uv sync --frozen
uvx library-skills --check
```

### Установка в новом checkout или для другого агента

Выполните из корня репозитория после установки зависимостей:

```bash
uv sync --frozen
uvx library-skills
```

В интерактивном меню выберите навык FastAPI и целевой каталог используемого агента:

- `.agents/skills` — Codex и большинство coding agents.
- `.claude/skills` — Claude Code.
- При использовании обоих агентов можно выбрать оба каталога.

Для неинтерактивной установки текущая документация FastAPI приводит команду:

```bash
uvx library-skills install --skill fastapi --yes
```

Добавьте `--claude`, чтобы также установить навык для Claude Code:

```bash
uvx library-skills install --skill fastapi --yes --claude
```

Если установленная версия Library Skills сообщает, что подкоманда `install` недоступна, проверьте `uvx library-skills --help` и используйте синтаксис, поддерживаемый этой версией CLI. Не меняйте зависимости проекта вслепую. В текущем репозитории навык уже установлен, поэтому обычно достаточно проверить ссылку, а не устанавливать его повторно.

Проверяйте инструкции, поставляемые пакетами, перед включением. Не устанавливайте автоматически все найденные навыки: файлы навыков являются инструкциями, по которым агент действует, поэтому их следует считать недоверенным входом и проверять.

## Плагин FastAPI Cloud для coding agents

Плагин FastAPI Cloud и навык FastAPI выполняют разные задачи:

- **Плагин FastAPI Cloud:** создание и привязка проектов, облачные deployment workflows, просмотр runtime/build logs и работа с переменными окружения.
- **Навык FastAPI:** код приложения на FastAPI, поддерживаемые API фреймворка, соглашения CLI и практики, соответствующие установленной версии FastAPI.

### ChatGPT и Codex

Используйте официальный плагин FastAPI Cloud в ChatGPT и Codex. Добавьте его через интерфейс плагинов соответствующего продукта.

В Codex CLI:

1. Запустите Codex и введите `/plugins`.
2. Найдите **FastAPI Cloud** в каталоге плагинов и установите его.
3. Начните новую сессию Codex, чтобы загрузились навыки плагина.

Примеры задач: попросить агента проверить последние runtime/build logs, подготовить deployment или проверить конфигурацию окружения приложения. Плагин не заменяет review репозитория, CI и production approvals.

### Claude Code

Официальный плагин распространяется через marketplace `fastapicloud/skills`. Выполните в Claude Code:

```text
/plugin marketplace add fastapicloud/skills
/plugin install fastapicloud@fastapicloud-skills
```

После установки начните новую сессию Claude Code. Плагин предоставляет следующие навыки:

| Навык | Назначение |
|---|---|
| `/fastapicloud:fastapi-new` | Создание нового FastAPI-проекта |
| `/fastapicloud:fastapicloud-deploy` | Подготовка и deployment приложения |
| `/fastapicloud:fastapicloud-logs` | Просмотр runtime- и build-логов |
| `/fastapicloud:fastapicloud-env` | Управление переменными окружения и секретами |

Claude Code может выбирать подходящие навыки автоматически; также их можно вызывать явно по именам из таблицы.

## Конфигурация приложения Pharmaviyum

Фактическая точка входа приложения настроена в корневом `pyproject.toml`:

```toml
[tool.fastapi]
entrypoint = "src.pharmaviyum.main:app"
```

Не заменяйте её общим примером `main:app` из документации фреймворка. Указанный путь соответствует объекту приложения в `src/pharmaviyum/main.py`.

Полезные команды из корня репозитория:

```bash
# Локальный сервер разработки с автоматической перезагрузкой
uv run fastapi dev

# ASGI-сервер в production-режиме (для самостоятельно управляемой среды)
uv run fastapi run
```

## Ограничения production deployment

У Pharmaviyum одно production-приложение в FastAPI Cloud. Production deployment намеренно контролируется ручным GitHub Actions workflow:

` .github/workflows/deploy-fastapi-cloud.yml `

Для production-релизов используйте защищённый workflow **Deploy to FastAPI Cloud**. Не используйте плагин агента или прямую команду CLI для обхода CI gate по точному commit SHA, проверок deployment inputs, проверки совместимости схемы БД, сериализации deployment и smoke tests после развёртывания.

Сейчас workflow отправляет deployment командой:

```bash
uv run fastapi cloud deploy . --no-wait
```

Эта команда является частью проверенного workflow, а не инструкцией развёртывать production из произвольной локальной сессии. Запрос агенту «deploy this app» всё равно должен соблюдать ручную release policy репозитория. Успешная отправка deployment-команды не означает успешный rollout: необходимо проверить точный build SHA в `/version`, версию CPython, `/health`, `/ready`, авторизацию и защиту POS.

Никогда не вставляйте секреты в prompts, не коммитьте значения переменных окружения и не просите агента вывести значения секретов. Изменение production environment variables требует отдельного явного разрешения и соблюдения production change-control. Миграции БД выполняются отдельно и только после явного утверждения; ни плагин, ни обычный deployment workflow не должны запускать их неявно.

## Текущая настройка Library Skills

Выполняйте из корня репозитория:

```bash
uv sync --frozen
uvx library-skills
```

Проверьте найденные навыки и устанавливайте только те, которые нужны проекту. Не используйте `--all` без проверки.

Для React frontend сначала установите зависимости, затем запустите сканирование из каталога frontend:

```bash
cd frontend/shadcn-admin
bun install --frozen-lockfile
npx library-skills
```

Проверки Python и frontend выполняются отдельно, поскольку используют разные окружения зависимостей. Оставляйте frontend-навыки в пределах frontend-проекта, если нет осознанной причины размещать их в корне репозитория.

## Полезные команды

| Назначение | Python | JavaScript/TypeScript |
|---|---|---|
| Обнаружить навыки (JSON) | `uvx library-skills scan --json` | `npx library-skills scan --json` |
| Проверить установленные навыки | `uvx library-skills list --json` | `npx library-skills list --json` |
| Проверить управляемые ссылки | `uvx library-skills --check` | `npx library-skills --check` |
| Синхронизировать управляемые ссылки | `uvx library-skills` | `npx library-skills` |

В репозитории также хранится навык Library Skills по адресу `.agents/skills/library-skills/SKILL.md`, чтобы будущие агенты знали, как обнаруживать и обслуживать навыки. CI выполняет `library-skills --check` после установки Python-зависимостей и выявляет сломанные или устаревшие управляемые ссылки.

## CI-аудит

Существующий CI сканирует Python-окружение в backend lint job, а JavaScript/TypeScript-окружение — в frontend checks job. Каждый job загружает JSON-отчёт об обнаруженных навыках как workflow artifact для pull request и push в main.

Аудит намеренно ограничен обнаружением. Он не устанавливает произвольные сторонние инструкции, не меняет зависимости, не создаёт symlink-ссылки и не выполняет deployment в production. После проверки отчётов разработчик может установить выбранные навыки и закоммитить созданные управляемые ссылки.

## Обслуживание и безопасность

- Повторяйте discovery после изменения `pyproject.toml`, `uv.lock`, `frontend/shadcn-admin/package.json` или `frontend/shadcn-admin/bun.lock`.
- Коммитьте управляемые skill links, чтобы участники команды и coding agents использовали один и тот же проверенный набор. Относительные цели ссылок разрешаются после установки соответствующих зависимостей.
- Не редактируйте и не удаляйте ссылки, которыми управляет Library Skills. Для синхронизации повторно запускайте CLI.
- Не устанавливайте все обнаруженные навыки без проверки. Считайте инструкции пакетов недоверенным содержимым: проверяйте источник, область действия, разрешения и релевантность.
- Эта интеграция относится к инструментам разработки. Она не добавляет runtime-зависимости и не влияет на сборку FastAPI Cloud, выбор версии Python, production secrets, миграции БД или deployment workflows.
