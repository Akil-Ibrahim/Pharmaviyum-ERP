# ADR-0004: Изолированная offline-оценка Ragas

[English](./ADR-0004-offline-ragas-evaluation.md) · **Русский**

## Статус
Принято — Ragas используется для offline-оценки и не входит в production request path.

## Контекст
Mortarium использует LangGraph для production-оркестрации агента и RAG. Ragas предоставляет метрики оценки, однако вызовы LLM-оценщика, embeddings и эталонные датасеты имеют иные характеристики стоимости, конфиденциальности и воспроизводимости, чем реальные запросы фармацевтов. Установка evaluation-фреймворков в production runtime увеличила бы поверхность атаки и добавила ненужные зависимости и обращения к провайдерам.

## Решение
- Хранить Ragas в группе зависимостей `eval` файла `pyproject.toml`, а разрешённые версии фиксировать в `uv.lock`. Для CI/offline-оценки устанавливать группу командой `uv sync --frozen --group eval`; не выбирать эту группу при установке production runtime.
- Выполнять оценку в CI или контролируемой offline-среде, а не при обработке HTTP-запросов FastAPI.
- Явно передавать адаптеры LLM-оценщика и embeddings; не переиспользовать production credentials автоматически.
- Использовать синтетические или одобренные обезличенные датасеты. Никогда не коммитить реальные записи пациентов, рецепты или клинические диалоги.
- Фиксировать и тестировать версию API адаптера Ragas.
- Рассматривать метрики LLM-as-a-judge как свидетельство регрессии, а не как клиническую валидацию или регуляторную сертификацию.
- Сохранять детерминированные аптечные проверки наряду с Ragas: поля лекарственных препаратов, полярность отрицаний, изоляцию контекста пациента, citation ID и подтверждение утверждений источниками.

## Последствия
Production-зависимости и latency не связаны с Ragas. Для воспроизводимости оценки необходимо фиксировать версии датасета, corpus/index, модели-оценщика, prompt/template и зависимостей. Утверждение порогов и разбор результатов требуют участия квалифицированного фармацевтического/клинического специалиста. Успешное прохождение evaluation suite само по себе не разрешает production rollout.
